# 🎨 VERSION TEST - STYLE ANETO

Cette version test s'inspire du design épuré et moderne du site ANETO (https://aneto.fr/).

## ✨ **CARACTÉRISTIQUES DU DESIGN**

### **Esthétique**
- **Fond blanc pur** pour un look épuré
- **Typographie Inter** moderne et lisible
- **Couleurs sobres** : bleu marine (#1a365d) + vert accent (#48bb78)
- **Espaces blancs généreux** pour la respiration
- **Animations subtiles** au scroll

### **Structure**
- **Header fixe** transparent avec effet de scroll
- **Hero section** avec photo de Vincent à droite, contenu à gauche
- **Stats visuelles** : années d'expérience, clients, levées de fonds
- **3 sections valeurs** avec icônes et cartes hover
- **3 services détaillés** avec listes à puces
- **Témoignage client** centré et impactant
- **CTA final** sur fond bleu avec 2 boutons

### **Expérience Utilisateur**
- **Navigation fluide** avec ancres
- **Mobile responsive** complet
- **Transitions CSS** douces
- **Hover effects** sur cartes et boutons
- **Scroll animations** avec Intersection Observer

## 📁 **FICHIERS**

- `index.html` - Page d'accueil style ANETO
- `aneto-style.css` - Feuille de style complète inspirée d'ANETO
- Autres fichiers copiés depuis la version originale

## 🖥️ **POUR TESTER**

1. Ouvrir `index.html` dans un navigateur
2. Tester sur desktop et mobile
3. Vérifier les animations au scroll
4. Tester les boutons et liens

## 🎯 **DIFFÉRENCES AVEC L'ORIGINAL**

| Aspect | Original | Style ANETO |
|--------|----------|-------------|
| Fond | Bleu turquoise | Blanc pur |
| Typographie | Inter standard | Inter + hiérarchie claire |
| Layout | Plus compact | Très aéré, espaces blancs |
| Hero | Centré avec emojis | Stats + boutons modernes |
| Navigation | Colorée | Minimaliste transparente |
| Sections | Basiques | Cards avec hover effects |
| CTA | Orange/rouge | Bleu corporate |

## ✅ **AVANTAGES**

- **Plus professionnel** et corporate
- **Meilleure lisibilité** avec les espaces blancs
- **Design moderne** dans l'air du temps
- **Navigation plus intuitive**
- **Expérience mobile optimisée**
- **Charge plus rapide** (CSS optimisé)

Cette version conserve tout le contenu existant mais avec une présentation beaucoup plus moderne et professionnelle, dans l'esprit d'ANETO.
