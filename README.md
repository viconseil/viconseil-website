# 🎨 VI Conseil V2 - Style ANETO

Site web professionnel pour Vincent, DAF externalisé et consultant finance.

## ✨ **Nouveau Design**

Version modernisée inspirée du site ANETO avec :
- **Design épuré** fond blanc et typographie moderne
- **Navigation cohérente** sur toutes les pages
- **Style professionnel** adapté au secteur financier
- **Responsive parfait** mobile/desktop

## 🏗️ **Structure du Site**

- `index.html` - Page d'accueil avec hero + services + témoignage
- `services.html` - Services détaillés + méthodologie
- `apropos.html` - À propos + expertise + comparatif économique
- `contact.html` - Contact + formulaire + processus
- `client-login.html` - Connexion espace client
- `client-dashboard.html` - Dashboard client

## 🎨 **Design System**

- `aneto-style.css` - Feuille de style principale inspirée d'ANETO
- `client-styles.css` - Styles spécifiques espace client
- Police : Inter (moderne et professionnelle)
- Couleurs : Bleu marine (#1a365d) + Vert accent (#48bb78)

## 🚀 **Fonctionnalités**

- ✅ Navigation unifiée sur toutes les pages
- ✅ Formulaire de contact avec EmailJS
- ✅ Espace client sécurisé (démo)
- ✅ Animations au scroll
- ✅ Mobile responsive
- ✅ Mode environnement (dev/prod)

## 📱 **Technologies**

- HTML5 sémantique
- CSS3 avec variables CSS
- JavaScript vanilla
- EmailJS pour les formulaires
- Intersection Observer pour animations
